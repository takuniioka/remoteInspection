DynamoDB Table Schemas
======================

Inspections
-----------
PK: inspectionId (String)
- title (String)
- place (String)
- status (String) [draft|running|closed]
- realtimeRef (String, optional)
- createdAt (String, ISO8601)
- startedAt (String, optional)
- endedAt (String, optional)
- createdBy (String)

ChecklistItems
--------------
PK: inspectionId (String)
SK: itemId (String)
- label (String)
- result (String) [ok|ng|pending]
- comment (String)
- updatedAt (String, ISO8601)
- updatedBy (String)

Issues
------
PK: inspectionId (String)
SK: issueId (String)
- title (String)
- detail (String)
- status (String) [open|resolved|closed]
- assignee (String, optional)
- createdAt (String, ISO8601)
- createdBy (String)
- updatedAt (String, ISO8601)
- updatedBy (String)

CaptureRequests
---------------
PK: inspectionId (String)
SK: captureRequestId (String)
- requestedAt (String, ISO8601)
- requestedBy (String)
- state (String) [requested|capturing|uploaded|failed|timeout]
- capturedAt (String, optional)
- uploadedAt (String, optional)
- photoId (String, optional)
- linkedType (String, optional) [checklistItem|issue]
- linkedId (String, optional)
- failReason (String, optional)

EvidencePhotos
--------------
PK: inspectionId (String)
SK: photoId (String)
- captureRequestId (String, optional)
- s3OriginalKey (String)
- s3AnnotatedKey (String, optional)
- s3AnnotationJsonKey (String, optional)
- capturedAt (String, ISO8601)
- uploadedAt (String, ISO8601)
- annotatedAt (String, optional)
- linkedType (String, optional) [checklistItem|issue]
- linkedId (String, optional)
- note (String)

AnnotationTemplates
-------------------
PK: templateId (String)
SK: version (Number)
- name (String)
- description (String)
- isActive (Boolean)
- definitionJson (Map)
- createdAt (String, ISO8601)

ViewerLinks
-----------
PK: viewerAccessToken (String)
- inspectionId (String)
- expiresAt (Number, Unix timestamp, used as TTL)
- isRevoked (Boolean)
- maxUses (Number, optional)
- usedCount (Number)
- createdAt (String, ISO8601)
- createdBy (String)

AuditLogs
---------
PK: logId (String)
SK: timestamp (String, ISO8601)
- userId (String)
- action (String)
- inspectionId (String, optional)
- details (Map)

WebSocket Messages (from ws-schema.json)
========================================

capture.request → capture.ack → capture.uploaded/failed/timeout
capture.request:
  - type: "capture.request"
  - inspectionId, requestedBy
  - linkedType (optional), linkedId (optional)

capture.ack:
  - type: "capture.ack"
  - inspectionId, captureRequestId, requestedAt, requestedBy, state: "requested"

capture.uploaded:
  - type: "capture.uploaded"
  - inspectionId, captureRequestId, photoId, uploadedAt, state: "uploaded"
  - linkedType (optional), linkedId (optional)

capture.failed:
  - type: "capture.failed"
  - inspectionId, captureRequestId, state: "failed"
  - failReason

capture.timeout:
  - type: "capture.timeout"
  - inspectionId, captureRequestId, state: "timeout"

checklist.updated:
  - type: "checklist.updated"
  - inspectionId, itemId, label, result, comment, updatedAt, updatedBy

issue.updated:
  - type: "issue.updated"
  - inspectionId, issueId, title, detail, status, assignee (optional)
  - createdAt, updatedAt, updatedBy

photo.annotation.updated:
  - type: "photo.annotation.updated"
  - inspectionId, photoId, s3AnnotatedKey, annotatedAt, updatedBy

connection.established:
  - type: "connection.established"
  - connectionId, serverTime

error:
  - type: "error"
  - code, message, details (optional)
